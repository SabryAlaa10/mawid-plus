منصة موعد+
من المريض إلى العيادة… بذكاء

منظومة متكاملة لحجز المواعيد ومتابعة الطوابير: تطبيق أندرويد للمريض، لوحة ويب لإدارة العيادة، ومساعد طبي ذكي (FastAPI) يدعم المحادثة واقتراح التخصص والأطباء مع ربط Supabase.

استكشف المشروع التقنيات المستخدمة

عن المنصة

تهدف موعد+ إلى تبسيط رحلة المريض: البحث عن طبيب، حجز موعد، متابعة الدور، والاستفادة من إرشادات أولية عبر مساعد ذكي — مع احترام خصوصية البيانات والربط الآمن بالخلفية السحابية.

مكونات المشروع

ثلاث طبقات رئيسية تعمل معاً على قاعدة بيانات ومصادقة موحدة.

📱

تطبيق المريض (Android)

Jetpack Compose، MVVM، Supabase Kotlin SDK، إشعارات، خرائط، وشاشات متعددة.

  • الرئيسية، البحث، الحجز، الطابور، المواعيد، الملف الشخصي
  • مساعد موعد+ (دردشة + بطاقة اقتراح طبيب)
  • واجهة عربية مع دعم RTL
Kotlin Compose Coroutines StateFlow
🖥️

لوحة الأطباء (ويب)

واجهة ويب لإدارة الجداول والمواعيد والطابور وربطها بـ Supabase.

  • جدول المواعيد وتصدير PDF
  • إدارة قائمة الانتظار
  • تكامل مع نفس قاعدة البيانات
React Supabase Vite
🤖

المساعد الذكي (FastAPI)

خادم Python يقدم REST API للمحادثة: RAG، نموذج لغوي، كشف تخصص، واستعلام أطباء من قاعدة البيانات.

  • مسارات: chat، doctors، appointments
  • تحقق من الجلسة عبر Supabase Auth
  • قاعدة معرفة طبية عربية
FastAPI Python RAG / LLM
