موعد+ — لماذا QR «ما يفتحش» لأصحابك؟ والحل
==========================================

لماذا لا يفتح عند «أي حد»؟
---------------------------
1) QR يشير إلى عنوان مثل http://192.168.x.x:8766/...
   هذا عنوان **داخل شبكة البيت/الجامعة فقط** (شبكة خاصة).
2) صاحبك على **باقة إنترنت الموبايل** أو **واي فاي تاني** = مش هيوصل لجهازك أبداً.
3) لازم **الكمبيوتر شغال** وعليه أمر: python -m http.server (من مجلد docs).
4) **جدار ناري Windows** ممكن يمنع الاتصال من موبايلات أخرى حتى على نفس الواي فاي.
5) لو **IP** جهازك اتغير، الرابط القديم في QR يبطل.

الخلاصة: QR على IP محلي ≠ إنترنت عام.


الحل الصحيح عشان «أي حد» يفتح من أي مكان
-----------------------------------------
استضافة الصفحة على **رابط عام (HTTPS)** ثم تعمل QR لذلك الرابط.

أبسط خيار مجاني لمشروعك على GitHub (المستودع: mawid-plus):

تم رفع مجلد docs وإضافة Workflow ينشر تلقائياً إلى فرع gh-pages عند كل push لـ docs.

أ) صلاحيات Actions (مرة واحدة إن فشل الـ workflow):
   Repository → Settings → Actions → General → Workflow permissions
   → اختر «Read and write permissions» → Save.

ب) بعد نجاح الـ workflow (تبويب Actions أخضر):
   Repository → Settings → Pages
   → Source: Deploy from a branch
   → Branch: gh-pages / folder: / (root)
   → Save

ج) بديل بدون gh-pages: يمكنك بدلاً من ذلك اختيار Branch = rewrite/sabry-web-auth و Folder = /docs
   (لن تحتاج انتظار الـ workflow إن كان المجلد موجوداً على ذلك الفرع).

1) تأكد إن مجلد docs (مع yom-elmy-mawid.html و assets/screenshots و index.html)
   مترفوع على GitHub (تم: commit + push).

2) إن لم تستخدم gh-pages: على GitHub: Repository → Settings → Pages
   - Build and deployment: Source = Deploy from a branch
   - Branch = نفس الفرع الذي يحتوي مجلد docs بعد الـ push (مثلاً rewrite/sabry-web-auth أو main)، Folder = /docs
   - Save

3) بعد دقيقة أو اثنتين، الموقع يكون تقريباً على شكل:
   https://sabryalaa10.github.io/mawid-plus/
   (يفتح index.html ويوجّه لصفحة العرض)

   أو مباشرة:
   https://sabryalaa10.github.io/mawid-plus/yom-elmy-mawid.html

4) ادخل على الرابط من موبايلك (بباقة الداتا) وتأكد إنه يفتح والصور ظاهرة.

5) أنشئ **QR جديد** من أي موقع QR ولصق الرابط العام أعلاه (مش 192.168...).


بدائل سريعة (بدون GitHub)
--------------------------
- Netlify Drop: اسحب مجلد docs كامل في netlify.com/drop
- Cloudflare Pages: ارفع مجلد docs
- ngrok: ينشئ رابط عام مؤقت لجهازك (للعرض ساعة مثلاً) — ابحث عن ngrok http 8766


مهم بعد الرفع
-------------
- أي تعديل على الصفحة أو الصور = push جديد وانتظر تحديث GitHub Pages.
- ملف QR القديم (yom-elmy-mawid-qr.png) لو كان لـ 192.168... استبدله بصورة QR للرابط العام.
